07 / SCHEMA & RLS — 13 tables
drizzle-orm • postgres 16
pgTable — core ledger (append-only)
• outlets {id, code, name}
• users {id, email, role: owner|manager|cashier}
• product_variants {sku, barcode, size, color, price}
• outlet_stocks {outlet_id, variant_id, qty} ← FOR UPDATE
• shifts {status: open|closed, float, expected, variance}
• sales {receipt_number UNIQUE, shift_id FK}
• sale_items {sale_id, variant_id, qty, tax}
• sale_returns {original_sale_id, reason_code}
• sale_return_items {return_to_stock}
• stock_movements {movement_type: sale|return|transfer_in|out|adjustment}
• transfers {status: in_transit|received}
• ledger_entries + audit_logs {actor, action, entity}
RLS — deny by default
• outlet_scoped: cashier/manager WHERE outlet_id = auth.outlet_id
• owner bypass: app_metadata.role = 'owner'
• shift gate: checkout requires shifts.status='open'
• no UPDATE on sales/sale_items/audit_logs
Transaction invariants • every write → audit_logs in same db.transaction()
• checkout: lock outlet_stocks → decrement → insert sale → stock_movements(sale)
• return: insert sale_returns → stock_movements(return) if return_to_stock
• receipt seq: INV-{OUTLET}-{YYYYMMDD}-XXXX (gapless)
